# Unit 02 - Version Control

## Overview
This unit focuses on understanding version control systems and how they are used in software development. Git and GitHub allow developers to track changes, manage projects, and collaborate with others.

## Learning Objectives
- Understand the purpose of version control.
- Learn essential Git commands.
- Create and manage Git repositories.
- Track changes through commits.
- Understand branches and merging.
- Use GitHub to store and manage projects.

## Skills to Develop
By completing this unit, I hope to become more comfortable using Git Bash, maintaining organized repositories, and documenting changes throughout the development process.

## Relevance to Backend Development
Version control is important for backend developers because it helps maintain code integrity, track updates, and support collaboration on software projects.
